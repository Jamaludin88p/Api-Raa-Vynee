TikTok

GET /api/tiktok

Ambil video (atau slide foto) TikTok tanpa watermark, lengkap dengan link audio.

parametertipewajibketerangan
urlstringyalink video TikTok

contoh request

GET https://zuradev.tools/api/tiktok?url=https://vt.tiktok.com/xxxxx

contoh response

{
  "status": true,
  "creator": "Web API Scraper",
  "result": {
    "title": "judul video",
    "author": "nama author",
    "username": "@username",
    "type": "video",
    "video": "https://...",
    "audio": "https://..."
  }
}

GET /api/ytmp3

Ambil link download audio dari video YouTube. File yang didapat adalah audio asli dari YouTube (biasanya .webm atau .m4a), bukan hasil konversi ke MP3 — cek field format di response untuk tahu ekstensi aslinya.

parametertipewajibketerangan
urlstringyalink video YouTube

contoh request

GET https://zuradev.tools/api/ytmp3?url=https://youtu.be/xxxxx

contoh response

{
  "status": true,
  "creator": "Web API Scraper",
  "result": {
    "title": "judul video",
    "duration": "213 detik",
    "channel": "nama channel",
    "thumbnail": "https://...",
    "type": "audio",
    "format": "webm",
    "note": "File audio asli dari YouTube (bukan konversi MP3)",
    "url": "https://..."
  }
}
